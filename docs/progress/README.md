# Daily Progress Reports

Per the kickoff brief's workflow expectations, this folder holds one
markdown file per reporting day, named `YYYY-MM-DD.md`, generated by the
Claude Code workflow configured for this repo. Each feature line follows
the brief's own example format:

> Account Creation. In progress. User tables and API endpoints complete.
> User views in progress.

A day's file is just a list of these lines, one per feature that changed
status that day - "Not started" / "In progress" / "Blocked (why)" /
"Complete" - so the project manager can scan it in under a minute.

See `TEMPLATE.md` for the structure a new day's file should follow.
